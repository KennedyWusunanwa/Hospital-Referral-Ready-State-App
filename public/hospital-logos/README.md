# Hospital logos

Logos for the facilities seeded by `supabase/migrations/0004_seed.sql`, referenced by
`0007_hospital_logo_seed.sql` as `/hospital-logos/<file>`. Each mark is the property of the
institution named and is used here solely to identify that institution inside the platform. A
hospital administrator can replace their facility's logo at any time from Administration →
Hospital, and a system administrator from the console; an uploaded logo is never overwritten by
the seed.
